criv

criv is an open-source Rust CLI that keeps repository documentation connected to the code it describes. Docs point at real files, symbols, and decisions; criv check fails when those references stop resolving. It runs locally, with no server and no network access.

Install with mise

Add to the repository's mise.toml:

[tools."github:TudorAndrei/criv"]
version = "0.7.0"

[tools."github:TudorAndrei/criv".platforms]
macos-arm64 = { asset_pattern = "criv-aarch64-apple-darwin.tar.gz" }
linux-arm64 = { asset_pattern = "criv-aarch64-unknown-linux-gnu.tar.gz" }
linux-x64   = { asset_pattern = "criv-x86_64-unknown-linux-gnu.tar.gz" }
windows-x64 = { asset_pattern = "criv-x86_64-pc-windows-msvc.zip" }

Then, from the repository root:

mise install
criv init                    # create criv.toml, docs/, docs/adr/, Git hooks
echo '.criv/' >> .gitignore   # generated state stays local
criv check                   # validate
